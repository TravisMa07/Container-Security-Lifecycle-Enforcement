## Scope and contracts

Collect Pods, Jobs, CronJobs, Deployments, ReplicaSets, StatefulSets, DaemonSets in one explicit namespace per invocation. Read-only HTTPS list/watch REST with explicit loopback API server, CA and token file. No default kube context, exec credential plugin, insecure TLS or real cloud endpoint. A namespaced ServiceAccount Role grants only get/list/watch for these resources; admin setup remains outside the collector. One thread per resource kind, one SQLite connection per thread. No new Python dependency. Parent owns adapter/coordinator/CLI, migration2, RBAC, pins/CI/status and real qualification. Agents own workload normalization and inventory persistence in nonoverlapping files; independent review read-only. No concurrent cluster qualification.

`app.workloads.normalize_object(cluster_id, namespace, kind, obj, event_type, source, observed_at) -> NormalizedResource` and `WorkloadObservation` use strict Pydantic/P0 contract shape. NormalizedResource fields: event_id, cluster_id, namespace, kind, name, uid, resource_version, event_type, source, observed_at, raw_object_hash, raw_object, observations. Validate matching namespace/kind, nonempty UID/name/RV and correct known shapes. Observe regular/init/ephemeral containers from Pod spec or controller template (CronJob jobTemplate.spec.template). Preserve owners, desired refs, raw runtime IDs, phase/replica values, acquisition/ingestion time. source_event_at stays null: object creation/condition timestamps are not generic watch-event timestamps. No fabricated deletion time.

Event ID hashes cluster/namespace/kind/UID/opaque RV/event_type/source; observation ID/idempotency key further hashes container category/name. Replays retain original acquisition times; same key with changed raw object rejects. No numeric RV ordering. Runtime resolution accepts only valid repo@sha256 identities, optionally the documented docker-pullable:// prefix; bare sha256/containerd config IDs stay unknown. Pod desired digest cannot silently establish runtime identity; controller desired digest can be parsed as a declared reference. Unknown IDs are retained. No validity/remediation/exposure verdict.

`app.store.inventory.InventoryStore(path)` context manager wraps P1 Store/connection and exposes:

- `bind_scope(cluster_id, namespace, server_id)` locks scope to hash of configured server URL+CA; token rotation is not a new cluster.
- `checkpoint(cluster_id, namespace, kind) -> dict|None` with resource_version and observed_at.
- `begin_gap(cluster_id, namespace, kind, reason, observed_at, started_at=None) -> gap_id`; one open gap per scope/kind, retain first reason/time. Append gap-start/close evidence rather than deleting history.
- `apply_snapshot(cluster_id, namespace, kind, objects, resource_version, observed_at, source='kubernetes_list') -> dict`. Normalize whole complete list before transaction; append snapshots and current membership atomically, set checkpoint and close an open gap. Previously current UIDs absent from list become present:false/absence_reason:RECONCILED_ABSENT, never fabricated DELETED events.
- `apply_event(cluster_id, namespace, kind, event_type, obj, observed_at) -> dict`. Atomic raw event, observations, membership and checkpoint. DELETED marks present:false but preserves raw history. Replay never overwrites initial timestamps. Bookmarks use `bookmark(cluster_id, namespace, kind, resource_version, observed_at)` and add no workload observation.
- `observations(cluster_id, namespace=None)`, `events(...)`, `current(...)`, `gaps(...)` return sorted JSON-compatible lists. Current entries include cluster/namespace/kind/name/uid, present, absence_reason, event_id, last_seen and observations (latest recorded resource). Gap entries include gap_id/cluster/namespace/kind/reason/started_at/ended_at (nullable). Store verifies raw/normalized hashes on reads and snapshot/event association; failed transaction leaves checkpoint/membership/history unchanged.

Parent migration2 adds inventory_events(event_id PK, payload TEXT), inventory_observations(observation_id PK,event_id FK,payload TEXT), inventory_current(cluster_id,namespace,kind,uid composite PK,event_id FK,present INTEGER,absence_reason TEXT,last_seen TEXT), inventory_checkpoints(cluster_id,namespace,kind composite PK,resource_version TEXT,observed_at TEXT), inventory_scopes(cluster_id,namespace composite PK,server_id TEXT), inventory_gap_events(gap_event_id PK,gap_id,cluster_id,namespace,kind,event_type,reason,observed_at,started_at). Events, observations and gap events have append-only guards. Scope/checkpoints/current are replaceable derived state. Never edit applied migration1. P1 CLI db init reports actual schema version after migration2.

## Adapter and recovery

`app.collectors.kubernetes.KubeAPI(server,ca_file,token_file,namespace)` with `server_id`, `list(kind) -> (objects, rv)`, `watch(kind,rv,timeout_seconds) -> iterator[dict]`. Resource API paths explicit (core/v1; apps/v1; batch/v1). Strict byte/depth limits via shared decoder; list pagination limit500, max10000 objects, complete consistent RV/continuation before store changes. Transport errors, malformed events, forbidden access and 410 become typed `KubeError` with status code, never success or empty inventory. HTTPS verifies CA/server; no redirects/proxy routing/token output. Token file owner-only; unsupported remote endpoints reject.

`Collector(api, db_path, cluster_id, namespace, reconcile_seconds=30, watch_seconds=5)` owns one resource loop per kind. Startup/restart always opens a conservative gap from last verified contact (or startup for new scope), completes relist and watches from list RV. Watch ADDED/MODIFIED/DELETED persist atomically; BOOKMARK checkpoints only. A 410 or disconnect opens a gap, relists and resumes. Early EOF (<bounded timeout) is a disconnect; normal timeout resumes from checkpoint. Periodic reconcile opens a bounded reconciliation-window gap because relist can skip unseen transitions; it converges current state without inventing events. Failed relist leaves the gap open and checkpoint intact, then retries with bounded backoff. Explicit stop opens COLLECTOR_STOPPED gap; unclean kill is detected conservatively at next startup. A workload entirely inside downtime remains unknown, never reconstructed by later list. Current snapshots prove only that kind/namespace at their timestamps, not globally atomic inventory or full historical coverage.

CLI: `inventory collect --cluster ID --namespace NS --server URL --ca FILE --token-file FILE [--duration SECONDS] [--reconcile-seconds N] [--watch-seconds N]`; `inventory workloads|events|observations|gaps --cluster ID [--namespace NS]`. Global --db retained. collect bounded duration optional (default runs until interrupt); JSON summary on completion, nonzero on persistent/observed transport/parse failure even if retry succeeds (durable gaps remain). Read queries deterministic; P1 exit semantics retained. No secret values in errors/logs.

## Source/review refinements

Actual Kubernetes typed lists omit item TypeMeta; the adapter supplies absent kind/apiVersion from the requested typed endpoint and rejects contrary values. Raw hashes identify this canonical decoded representation, not original wire whitespace. A separate immutable complete-snapshot receipt is required for observed absence history: migration3 appends inventory_snapshots(snapshot_id PK,payload TEXT) with update/delete guards, leaving already executed migration2 unchanged. Receipts hash scope/kind/source/list RV/time plus sorted UID/event-ID membership; empty membership is evidence of that complete snapshot only. `InventoryStore.snapshots` and `inventory snapshots` expose validated receipts; snapshot/event/current/checkpoint/gap-close changes are atomic. No earlier receipts are backfilled from mutable state.

Independent review showed that server identity must bind across all namespaces for a cluster ID, preserving canonical (cluster_id,UID) identity. New bind_scope checks the full cluster binding. Namespace-list raw bytes are capped cumulatively at20MiB, not multiplied by pagination. A per-DB/cluster/namespace advisory lease serializes collectors. These corrections preserve the original coverage/identity expectations; no phase scope or security gate was waived.
