Base: `eb54a6d557c697a70ee2262d948d9016686d2375` (merged P0). Authority: HANDOFF sections 4, 5, 12/P1, 14, 15 and S11/S12/S14. Parent owns integration, CLI, runner, dependency pins, CI and status. Scoped agents own parser/models and store respectively; independent read-only review owns no implementation files. No cluster qualification runs concurrently.

## Bounded behavior

One Python application (`python -m app`, installed `csle` entry point), SQLite and no service. P1 owns typed image/finding/scan records, transactional migrations, immutable scan evidence, Trivy schema-2 vulnerability ingestion, deterministic JSON queries and an actual pinned scan. Other canonical models acquire executable behavior in their owning phases; P0 JSON schemas remain authoritative structural contracts. No policy verdict, signing, lifecycle closure, Kubernetes collector or compliance mapping is added.

CLI: global `--db PATH` (default `.local/csle.sqlite3`); `db init`; `scan import REPORT --image REPOSITORY@sha256:DIGEST [--scanner-version VERSION] [--db-metadata FILE]`; `scan image REF --registry-url LOOPBACK_HTTP --platform linux/arm64`; `scans list`; `scans show ID`; `findings list`; `findings explain ID`; `doctor`. Every command supports help. JSON is sorted and stable with newline; success 0, invalid arguments/input 2, execution/storage failure 1. Errors have code/message JSON on stderr and no partial success on stdout. No findings or empty Results produces no invented findings and no allow verdict.

## Interfaces and domain decisions

- `app.models`: strict Pydantic v2 `ImageArtifact`, `VulnerabilityFinding`, `ParsedScan`, scalar validators and canonical JSON/hash helpers. Match P0 image/finding schemas; enforce image_id == selected manifest == platform_digest when present, first<=last, UTC calendar dates, unique lists, and enums. Unknown scanner version is explicit `unknown` in findings; nullable scan metadata and limitations retain absence. No coercion of bool/int to strings.
- `app.collectors.trivy.parse_report(raw: bytes, image_ref: str, scanner_version: str | None = None, db_metadata: bytes | None = None) -> ParsedScan`. This parses untrusted input only. ParsedScan fields: `image`, `findings`, `source_document_hash`, `parser_version`, `scanner_version` (nullable), `scan_timestamp`, `scanner_db_updated_at` (nullable), `db_document_hash` (nullable), `limitations` (sorted unique strings). It never claims execution trust. Canonical finding IDs hash source=trivy + selected manifest + target + package type/path/name/installed version + vulnerability ID (not severity/fix/time); repeated occurrences deduplicate if identical, conflicting duplicates reject. Evidence IDs initially source_document_hash. Scanner output never overrides validity `under_investigation`.
- Accept only image schema 2 reports with timezone-aware CreatedAt and Metadata.RepoDigests binding to the exact supplied repository and digest. ImageID is config identity, never manifest identity. Repository reference is digest-qualified; mutable tags rejected in P1. Unknown fields in upstream scanner documents tolerated for forward-compatible additive fields; malformed known fields reject. Schema versions other than 2 and non-vulnerability result classes reject. Absent/null/empty vulnerabilities is an empty set; falsy wrong types reject. Absent/null/empty Results has explicit no-results limitation, not evidence of safety. Findings retain type/path, severity/source, target OS/platform, aliases where available. Missing severity becomes UNKNOWN with a limitation; invalid severity rejects. Missing fixed version becomes null. Missing report scanner version/DB fields stays unknown; conflicting declared versions reject. RFC3339 offsets normalize to UTC Z at adapter boundary.
- Input limits before parse: report 20 MiB, DB metadata 1 MiB, 10,000 results, 100,000 findings. Duplicate JSON keys, nonfinite numbers, malformed UTF-8 and nesting/shape errors reject. No user content is executed or fetched by import.
- `app.store.db.Store(path, migrations=None)` context manager; `initialize()`; `save_scan(parsed: ParsedScan, raw: bytes, db_metadata: bytes | None = None, provenance: str = 'imported', resolution: dict | None = None, execution: dict | None = None) -> dict`; `list_scans() -> list[dict]`, `get_scan(scan_id) -> dict | None`, `list_findings() -> list[dict]`, `get_finding(finding_id) -> dict | None`. Results use plain JSON-compatible values. Parent supplies only internal execution/resolution context; imported evidence cannot be upgraded in place. Scan ID deterministically hashes parser version, raw hash, image identity, scanner/DB metadata and provenance/context. Return save receipt `{scan_id, inserted}`. Lists sorted by stable IDs. Scan detail includes image, findings, raw hash, provenance, resolution/execution and limitations. Finding query returns canonical finding plus evidence_ids across scans, selecting latest scan timestamp then raw hash for display; all historical scan findings remain immutable.
- SQLite migrations numbered contiguously from 1, each an ordered tuple of SQL statements with stored content hash. BEGIN IMMEDIATE transaction includes DDL, version ledger and ingestion; no executescript implicit commit. Changed applied migration or newer database rejects. Foreign keys on, busy timeout bounded, append-only scan/raw/finding snapshots with SQL update/delete guards; DB owner can still tamper offline, not a tamper-proof trust store. Reimport exact bytes/context is idempotent; changed context is distinct evidence. Raw bytes and optional DB metadata stored in SQLite and hash-checked on reads. No DB files in Git.
- Real runner resolves immutable OCI manifest bytes through explicit loopback HTTP endpoint, verifies requested hash, optionally resolves a requested index platform then verifies selected manifest/config bytes. Config OS/architecture must match requested platform. Trivy scans selected manifest remotely using pinned binary and separate cache, records exact executable version/hash, DB metadata/hash, argv and manifest/config resolution evidence. No shell, real AWS or Docker/Kubernetes mutation. Imported provenance never qualifies signing; P5 independently implements issuance trust.
